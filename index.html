Evidence before “done”

Select a task and simulate the minimum evidence needed for closure.

Risk ≠ authority

A low-risk change may still require permission if it acts on an external or protected surface. A higher-risk code change may still be reviewable without external authority.

Fail closed

Missing preflight, ambiguous scope, protected configuration or insufficient authorization does not silently degrade into “best effort” execution.

Closure is a state

“Implemented” is not equivalent to “validated.” Completion requires declared checks, evidence and a verifier result appropriate to the task.
