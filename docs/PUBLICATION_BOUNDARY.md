# Publication Boundary

This repository is a public portfolio demonstration, not the canonical Wii Ops Center.

## Public

- high-level agentic operations architecture;
- synthetic task-routing demo;
- generic preflight concepts;
- separation of change risk and authority;
- bounded-autonomy pattern;
- verifier/evidence/closure concepts;
- deterministic public-demo tests.

## Private

- canonical routing thresholds and policy tables;
- provider/model routing configuration;
- credentials, endpoints and runners;
- real workspaces, projects, clients and incidents;
- internal task packets and operational memory;
- production release/deploy controls;
- auto-merge implementation details;
- standing authorizations;
- kill switches and protected governance surfaces;
- private audit evidence;
- economic/provider-selection logic.

## Rule

The showcase should prove the engineering pattern without giving a third party the operational control plane itself.
